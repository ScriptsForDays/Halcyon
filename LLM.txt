# Halcyon: reference for AI coding assistants

Halcyon is a Roblox UI library for script hubs, written in Luau and loaded as one file. This file is the complete public API, written so an assistant can build with it without guessing. Use only what is listed here; do not invent options, methods, looks or icon names.

This file describes Halcyon 2.3.1. If your training data shows an older Halcyon, trust this file: options and methods listed here exist, and anything not listed does not.

Read in this order:
1. "Mental model" and "Rules" (short, prevent most mistakes).
2. "I want to..." to find the right part, then that part's entry in "Components".
3. "Recipes" for whole patterns (a feature with cleanup, a farming loop, configs), and "Wrong and right" before you hand code over.
4. docs/llm-guide.md before laying out a whole hub: it explains how to choose controls, how much to put on a tab, and what to leave out. It gives reasons, not a fixed design.

While building, put `Debug = true` on CreateWindow. Halcyon then warns, once each, about option names it doesn't know (with the name it thinks you meant), misspelt looks and unknown themes. Read those warnings and fix them; remove Debug before shipping.

Longer human docs: docs/api.md, docs/styles.md, docs/key-system.md, docs/themes.md, docs/icons.md. Editor types: dist/Halcyon.types.luau.

## New in 2.3

- Values: every handle has `SetSilent(value)` (no Callback), `Reset()` and `GetDefault()`. The window has `GetValues()`, `SetValues(table, silent)`, `ResetValues()` and `Undo()`.
- Configs: share codes (`ExportConfig()`, `ImportConfig(code)`) that work without file functions, copy and paste rows in the config block, and per-game configs (`Configs = { PerGame = "Place" }`).
- Callbacks: a failing callback shows its reason under its row and is kept in `Window.Errors`; a Button whose callback yields shows its spinner until it returns.
- `Debug = true`, `Language`, `Strings`, `Halcyon:SetDebug`, `SetLanguage`, `SetStrings`.
- Notices: `Countdown` (Bar, Edge, Ring, Top, None), `Id` updates a notice in place, repeats fold into one with a count, `Image`/`Avatar`, `OnClick`, `OnDismiss`, `Stack = "Deck"`, `ClearNotifications()`.
- Elements: Viewport, Gauge, Knob, Chart, ItemGrid, Waypoints. Keybind `Modifiers`, Button `Keybind`, Toggle `Exclusive` and `Confirm`, Input `Validate` and `SetError`.
- Navigation: `Tab:Page` / `Section:Page` sub-pages, `Favourites`, `TabReorder`, Section `PopOut`, search marks and counts matches and `JumpToMatch` steps through them.
- Looks: moving `Background` on the window and on sections.
- Services: `UpdateCheck`, `SupportPanel()`, `ErrorsPanel()`.
- Extending: `Halcyon:RegisterElement`, `Halcyon:Build(spec)`.
- The resize grip keeps the window's corner under the pointer wherever the window sits.
- 2.3.1: `Translate = true` shows the hub's own text in the player's language (see "Translation"); longer words stay inside their boxes.

## Load

```lua
local Halcyon = loadstring(game:HttpGet("https://raw.githubusercontent.com/ScriptsForDays/Halcyon/main/dist/Halcyon.luau"))()
```

Roblox Studio: paste dist/Halcyon.luau into a ModuleScript named Halcyon in ReplicatedStorage, or insert dist/Halcyon.rbxmx, then `require(game.ReplicatedStorage.Halcyon)` from a LocalScript.

## Minimal hub

```lua
local Window = Halcyon:CreateWindow({ Title = "My Hub", Icon = "gamepad-2", Folder = "MyHub" })
if not Window then return end -- needed only with a KeySystem (the player can close the prompt)

local Player = Window:Tab({ Title = "Player", Icon = "user" })
local Movement = Player:Section({ Title = "Movement", Icon = "footprints" })

Movement:Toggle({ Title = "Fly", Description = "WASD to steer", Flag = "Fly", Callback = function(on) end })
Movement:Slider({ Title = "Walk speed", Min = 16, Max = 120, Default = 32, Suffix = " st/s", Flag = "WalkSpeed", Callback = function(speed) end })

Window:SettingsTab()
Window.OnUnload:Connect(function() --[[ stop features, restore what you changed ]] end)
Window:LoadAutoload()
```

## Mental model

- **Window**: one per hub. Top bar (title, version tag, search, minimise, close), navigation (sidebar, rail, top strip or bottom dock), pages, and an optional profile card. Running the same hub again (same `Folder`) unloads the old window first.
- **Tab**: a page. Has a button in the navigation. Tabs can share a sidebar `Group` heading.
- **Section** ("groupbox"): a titled box of rows on a tab. A wide window shows two columns; `Side = "Right"` puts a section in the second one. On a narrow window everything stacks in creation order.
- **Row**: every element is a row: title and description on the left, its control on the right. Narrow rows move wide controls under the title.
- **Handle**: every element returns a handle with `Get`, `Set`, `Changed` and the shared methods below.
- **Flag**: a unique string on an element. Flagged values are saved in configs and restored by `LoadConfig`/`LoadAutoload`.
- **Looks**: every kind of control has named looks (`Style`). Defaults are always fine; looks are optional polish. See "Looks and presets".
- **Lifecycle**: `CreateWindow` (may yield for a key prompt), build tabs and elements, `LoadAutoload()` last, `OnUnload` for cleanup. `Window:Unload()` or the Unload button removes everything Halcyon made.
- **Theme**: colours are roles (`accent`, `text`, `surface`...), never literal colours. Changing the theme recolours everything already on screen.

## Rules

1. Every constructor takes ONE table: `Section:Toggle({ Title = "Fly" })`. `Label("text")` is the only string shortcut (also valid for Tab).
2. `Title` is required on every element except Divider, Code, Image, Buttons, Table, Space and Stats.
3. A `Flag` must be unique in the window; a duplicate raises an error. Flag only what should be saved.
4. `Set(value)` always runs the Callback, even for the same value. Creating an element never does, except a Toggle with `Default = true`, whose Callback runs once, deferred, after the hub finishes building.
5. A Slider's `Default` is only displayed. Apply the starting value to the game yourself if needed.
6. With a `KeySystem`, `CreateWindow` yields and returns `nil` if the player closes the prompt: `if not Window then return end`.
7. Call `Window:LoadAutoload()` last.
8. Cleanup goes in `Window.OnUnload:Connect(...)`. Do not add your own "already running" guard; a second run replaces the first.
9. Notify for results the player cannot see (saved, failed, loaded, finished). Never notify for each toggle.
10. Name tabs for contents ("Combat", "Visuals"), not "Main"/"Misc". Name toggles for the feature ("Fly"), not "Enable fly"/"Toggle fly".
11. File-backed features (configs, keys, settings, URL images) need executor file functions. Calls return `false, message` without them; show the message, never claim success.
12. Icons are Lucide names (`"house"`), `"pack:name"`, asset ids, URLs or workspace files. Never emoji or text glyphs as icons.
13. A client-side key prompt is not security. Never describe it as protecting the script.
14. Do not set looks element by element across a hub. Leave defaults, or use one `Preset` / one window `Styles` table.
15. Use only features listed here. If the user asks for something Halcyon lacks, say so instead of inventing an option.
16. To leave a built-in part out, set its switch to `false` on CreateWindow (see "Switches"). Do not hide library instances by hand.
17. To change a control from code without running its Callback (mirroring game state onto the UI, keeping two controls in step), use `SetSilent(value)`. Calling `Set` inside the same element's Callback or Changed handler loops forever.
18. Never translate or reword Halcyon's own text by editing instances. Use `Language` or `Strings` on CreateWindow (see "Translation").
19. A Callback may yield (task.wait, HTTP); Halcyon runs it on its own thread. Don't wrap callbacks in task.spawn or pcall yourself: Halcyon already catches errors and shows them on the row.
20. Long-running work started by a Toggle must stop when the Toggle turns off and on Unload. See "Recipes".
21. Turn on `Debug = true` while writing a hub and fix every `[Halcyon debug]` warning.

## CreateWindow options

All optional. Defaults in brackets.

**Identity**
- `Title` ["Halcyon"], `Subtitle`, `Icon` (any image source; false for none), `Version` (tag beside the title, e.g. "v1.2.0"), `ShowVersion` [true]
- `Folder` [Title]: save folder and hub identity. Keep it stable across releases.
- `TopbarImage`: a picture before the title (image source, or `true` for `Icon`; false for none); `TopbarImageStyle`: "Circle" | "Rounded" | "Square" | "Squircle" | "Ring" | "Badge" ["Circle"]
- `HeaderStyle`: "Bar" | "Tall" | "Wordmark" | "Sidebar" ["Bar"]. Sidebar: big logo above the sidebar, search under it, no top bar.
- `Logo`: image source, or `{ Image, Text, Icon, Height, Width }`, or false. Without an image it draws `Text` (or Title) as a wordmark.

**Layout**
- `Size` [Vector2.new(740, 500)], always fitted to the screen; `Scale` 0.75-1.25 [1]
- `TabStyle`: "Sidebar" | "Rail" | "Top" | "Dock" ["Sidebar"]; narrow windows use "Top"
- `SidebarWidth` 150-280 [196]; `SidebarToggle` [false]: a top-bar button folding the sidebar to the rail
- `CollapsedGroups`: sidebar groups that start folded; `CollapsibleGroups` [true]
- `MinimizeStyle`: "Topbar" | "Pill" | "Chip" ["Topbar"]; `Minimize` [true] (old name Minimizable); `Resize` [true, mouse only] (old name Resizable); `Close` [true]; `Drag` [true]; `Snap` [false]
- `ToggleKey` [Enum.KeyCode.RightShift]; `OpenButton` [false; always on for touch]

**Looks** (see "Looks and presets")
- `Preset`: "Classic" | "Minimal" | "Glass" | "Neon" | "Compact"
- `Styles = { Kind = "Look" }`; single options: `SectionStyle`, `TabIndicator`, `WindowStyle`, `OpenAnimation`, `PageTransition`, `TopbarControls`, `ButtonEffect`, `ToggleThumb`, `SliderTooltipStyle`
- `Radius`: "Sharp" | "Soft" | "Default" | "Round"; `Density`: "Compact" | "Default" | "Spacious"; `TextSize`: "Default" | "Large" | "Larger"
- `Theme` (name or palette table), `Font`, `IconPack`, `AccentGradient` (true or Color3), `SafeStatusColors` [false]
- `Background = { Kind = "Aurora" | "Glow" | "Gradient" | "Mesh" | "Pattern" | "Image", Colors = { "accent", "info" }, Speed = 1, Intensity = 0.75, Sheen, Vignette, Image }`: a moving background behind the content (also on a Section, where Intensity defaults to 0.3). Aurora: fields of light drifting and breathing (past the window's edges; inside a section's). Glow: a soft light that follows the pointer over the surface, best on one section. `Sheen = true`: a band of light crosses it, 0.8 seconds after the last one. `Vignette`: shaded edges, on by default behind the window. `SeeThrough` [0.35, up to 0.6]: how much of a window background shows through solid section cards. Default colours are the accent, two neighbouring hues and info. Tween-driven, paused while hidden, still under reduced motion, recoloured by themes. `Window:SetBackground(spec)`, `section:SetBackground(spec)`; nil removes it. One moving surface per screen reads as polish; three competing ones read as noise.
- `Transparency` 0-0.6 [0]; `BackgroundImage`, `BackgroundImageTransparency` [0.75]; `Shadow` [true], `ShadowImage`, `ShadowTransparency` [0.5]
- `SliderTooltips` [true]; `ToggleOutline` [true], `ToggleOutlineColor`; `LockShimmer` [true]; `FocusRing` [true]

**Behaviour**
- `Favourites` [false]: players star rows from their right-click or long-press menu; a Favourites tab at the top shows live copies (changing either side changes both; only the original holds the Flag). While empty, the tab says how to add rows. `Favourite = true` on a row starts it there on the first run. Remembered per hub.
- `TabReorder` [false]: players drag tabs to reorder them within their group, or pin and move them from the tab's menu. Remembered per hub.
- `Search` [true]; matches are marked, counted per section and in the box ("2 of 7"); Enter or Up/Down jumps between them with a light running round the row. `Window:JumpToMatch(1 or -1)`; `CommandPalette` [false] (Ctrl+K), `PaletteKey` [K]
- `Tooltips` [true]; `Animations` [true]; `Blur` [false; true or a size]; `NotificationCenter` [false]: a bell with past notices
- `Watermark`, `KeybindList`, `SettingsTab` [false]: true, or the same table their Window methods take
- `ConfirmUnload` [true]; `SavePreferences` [true]; `DisplayOrder` [2147483000]
- `UpdateCheck = { Url, Current, Notify, OnUpdate }`: a moment after opening, reads Url (plain text "2.4.0" or JSON `{ "version": "2.4.0", "notes": "..." }`), and when it is newer than Current [the window's Version] shows a notice, fires `Window.UpdateAvailable` and calls OnUpdate(latest, notes). Never runs anything it downloads. `Window:CheckForUpdate()` -> ok, latest, notes.
- `Notifications = { Duration, Position, Progress, MaxVisible, Style, Sound }`
- `Configs = { PerGame = "Place" | "Universe" }`: configs and autoload kept per game
- `ShowErrors` [true]: a failing callback's message shows under its row
- `Debug` [false]: warns about unknown option names, misspelt looks and themes. Turn it on while building.
- `Language` ["en"]: "auto" or a code ("pt-br", "es", "vi", "id", "ru", "tr", "fr", "de"); `Strings = { ["English text"] = "your text" }` replaces built-in wording

**Access**
- `KeySystem` (see Key system); or `Tiers`, `Tier`, `PaidTier` for tiers without a prompt
- `LockText` ["Requires {tier}"], `PaidLockText` ["Paid only"], `LockHint`, `PaidLockHint` ["Unlock with a paid key"]

**Extras**
- `Profile`: false, or table (see Profile)
- `UpdateLog`: true, or table (see Update log)

## Switches

Every built-in part is an option: false leaves it out, true adds it, a table passes settings where noted. `Window:Set(name, value)` changes one while the hub runs; `Window:Get(name)` reads it.

Live switches: Search, Profile, ShowVersion, Minimize (Minimizable), Close, Resize (Resizable), Drag, Shadow, Tooltips, Animations, Blur, CommandPalette, Snap, OpenButton, Watermark, KeybindList, NotificationCenter, SettingsTab.
Read once at creation: Icon, TopbarImage, Logo, CollapsibleGroups, SliderTooltips, ToggleOutline, ConfirmUnload, LockShimmer, FocusRing, SavePreferences.

Tabs, sections and elements take, when made: `Visible = false`, `Disabled = true` (or `Enabled = false`), `ShowWhen = "Flag"` or `{ "Flag", value }` (shown while that flag holds value [true]; value may be a function), `EnableWhen` (the same, greyed instead of hidden). The flag may belong to an element made later.

## Window

**Methods**
- Structure: `Tab(options)`, `SelectTab(tab)`, `SettingsTab(options)`, `ConfigSection(tabOrSection, options)`, `PersonaliseSection(tab, options)`, `ThemeBuilder(tab, options)`, `About(tab, options)`
- Visibility: `Show()`, `Hide()`, `Toggle()`, `Minimize(bool)`, `SetMinimizeStyle(name)`, `SetEnabled(bool)` (greys every row), `Lock(options)`, `Unlock()`
- Look: `SetTabStyle(name)`, `SetScale(n)`, `SetTransparency(n)`, `SetAccent(color)`, `SetReducedMotion(bool)`, `SetPersonal(key, value)`, `SetSliderTooltips(enabled, style)`, `SetToggleOutline(enabled, color)`
- Top bar: `SetTitle`, `SetSubtitle`, `SetVersion`, `SetVersionVisible`, `AddTopbarButton({ Icon, Callback })` -> `{ Destroy }`, `Search(text)`, `OpenPalette()`
- Profile: `SetAnonymous(bool)`, `SetProfile(table)`
- Access: `GetTier()`, `HasTier(name)`, `IsPaid()`, `SetTier(name)`, `GetKeyExpiry()`, `SetLockText(text, paidText)`, `SetLockHint(hint, paidHint)`, `Require(names)` -> missing executor functions
- Support: `SupportPanel()` (what this executor offers, rows locked for it, a copyable report), `ErrorsPanel()` (failed callbacks with tracebacks), `Errors` list, `ErrorsChanged`, `ClearErrors()`. The Settings tab has rows for both (`Support`, `Errors` switches).
- Feedback: `Notify(options)`, `Dialog(options)`, `Loading(options)`, `Changelog(options)`, `AddUpdate(release)`, `Watermark(options)`, `KeybindList(options)`
- Switches: `Set(name, value)`, `Get(name)`
- Panels: `Sheet({ Title, Width = 340 })` (slides over the page; takes element calls; `Open()`, `Close()`, `IsOpen`), `QuickBar({ Items = { "Flag", toggleHandle, { Title, Icon, Callback } } })` (floating bar that stays while the window is hidden; `Add(item)`, `SetVisible`, `Destroy`)
- Configs: `SaveConfig(name)`, `LoadConfig(name)`, `DeleteConfig(name)`, `ConfigExists(name)`, `ListConfigs()`, `SetAutoload(name)`, `GetAutoload()`, `LoadAutoload()` (all return `ok, message` where relevant)
- Values: `GetValues()` -> flag = value, `SetValues(table, silent)` -> count set, `ResetValues()`, `Undo()` -> ok, message (restores what the last LoadConfig, ImportConfig, SetValues or ResetValues replaced)
- Share codes: `ExportConfig()` -> "Halcyon1:..." text, `ImportConfig(code)` -> ok, message. No file functions needed; players paste codes to each other.
- Search: `Search(text)`, `JumpToMatch(1 or -1)` -> the row it landed on
- Other: `SetBackground(spec)`, `SetLanguage(code)` (saved; applies fully on the next run), `CheckForUpdate()`, `ClearNotifications()`
- Ending: `RequestUnload()` (asks first unless ConfirmUnload = false), `Unload()`

**Fields**: `Flags` (flag -> handle), `Visible`, `access`, `Errors`, signals `OnUnload`, `TabChanged(tab)`, `ConfigChanged(action, name)`, `KeybindsChanged`, `ErrorsChanged(entry)`, `SectionPopped(section, open)`, `UpdateAvailable(latest, notes)`.

## Tab

`Window:Tab({ Title, Icon, Group, Description, SectionStyle, Tier, PaidOnly, LockText, LockHint, Visible, ShowWhen })`

- `Description` adds a page heading with that line under it.
- `Page({ Title, Description, Icon, Badge, Tier, PaidOnly })` (also on a Section): a sub-page with its own sections and rows, opened from a row on the parent and left by the back arrow, the breadcrumb or Escape. Pages nest, search finds rows inside them, and the navigation marks the tab they belong to. Use them for deep settings of one feature (Combat > Aimbot > Prediction), not as a second set of tabs.
- Methods: `Section(options)`, `Select()`, `SetTitle(text)`, `SetVisible(bool)`, `ShowWhen(source, value)`, `SetBadge(value)` (number, short word, true for a dot, nil to clear), `Notice({ Title, Content, Kind, Dismissible })` (callout at the top of the page) -> `{ SetContent, Destroy }`, `EmptyState({ Icon, Title, Text, Kind = "error", Button = { Title, Callback } })` -> `{ SetText, Destroy }`, `About(options)`.
- Every element method also exists on a tab; those rows go into an untitled flat section.

## Section

`Tab:Section({ Title, Icon, IconColor, Description, Badge, Style, Side, Collapsible, Collapsed, Tabs, Switch, MaxHeight, Tier, PaidOnly, LockText, LockHint, Visible, Disabled, ShowWhen, EnableWhen })`

- `Style`: Card (default), Outlined, Flat, Glass, Accent, Inset, Header, Panel (each row on its own inset card).
- `Side`: "Left" (default) | "Right".
- `Collapsible` [true]: the title folds it. `Collapsed` starts folded.
- `Tabs = { "Aim", "Visuals" }`: tabs inside the box. `section:Tab("Visuals"):Toggle({...})`; elements added to the section itself go to the first. `SelectTab(name)`.
- `Switch = { Default, Flag, Callback }`: a switch in the header; off greys every row in the section.
- `MaxHeight = 240`: rows scroll past that height.
- `PopOut = true`: a header button moves the rows into a floating panel (drag by its title bar, resize from the bottom-right corner) that stays on screen while the hub is hidden; it docks back from the panel or the note left in the section. `section:PopOut(open)`, `section:IsPoppedOut()`, `Window.SectionPopped(section, open)`. Position, size and whether it was out are saved. Good for live readouts and a few quick switches.
- `Tier` / `PaidOnly`: one overlay covers the section with `LockText` and `LockHint`.
- `Group({ Columns = 2 })`: a holder taking element calls that puts 2-3 controls on one line; they stack when narrow. Use for short pairs (Auto farm / Auto sell), not for sliders or lists.
- Methods: `SetTitle`, `SetBadge`, `SetCollapsed(bool)`, `SetVisible(bool)`, `SetEnabled(bool)`, `ShowWhen(source, value)`, `EnableWhen(source, value)`, `Group(options)`, `Destroy()`, and every element method.

## Every element

**Shared options**
- `Title` (string; see rule 2), `Description` (second line), `Icon` (leading icon)
- `Flag` (saved in configs), `Callback`
- `Tier`, `PaidOnly`, `LockText`, `LockHint` (lock this row)
- `Badge`: "New" | "Beta" | "Risky" | "Paid" | any text | `{ Text, Color }`
- `Info`: longer text behind an info icon
- `Tooltip`: hover text, or `{ Title, Text, Key, Style = "Card" | "Plain" | "Follow" }` (on a Slider, `Tooltip = true/false` is its value bubble instead)
- `Spotlight = { Title, Text, Id }`: a one-time pointer at a new feature, remembered once dismissed
- `Requires = { "hookfunction", ... }`: locks the row naming the executor functions that are missing
- `Style`: the element's look
- `Menu = { { Title, Icon, Callback, Danger, Disabled }, { Divider = true } }`: actions on right-click or long press of the row
- `Visible`, `Disabled`, `ShowWhen`, `EnableWhen`: see Switches
- `Favourite = true`: with `Favourites` on, the row starts in the Favourites tab the first time the hub runs; after that the player's own picks are kept

**Shared handle**
- `Get()`, `Set(value)`, `Changed:Connect(fn)`
- `SetTitle(text)`, `SetDescription(text)`, `SetDisabled(bool)`, `SetEnabled(bool)`, `SetVisible(bool)`
- `Lock(text, icon)`, `Unlock()`, `IsLocked()`
- `ShowWhen(elementOrFlag, valueOrFunction)`: visible only while another element has that value (a multi-select matches when it includes it; a function receives the value)
- `EnableWhen(elementOrFlag, valueOrFunction)`: the same, greyed instead of hidden
- `SetSilent(value)`: sets the value and fires Changed without running the Callback
- `Reset()`: back to the value it was made with; `GetDefault()` returns that value
- `Spotlight(options)`, `Destroy()`
- Fields: `Frame`, `Kind`, `Flag`, `Title`, `Options` (the table it was made with)
- A Callback that errors shows its reason under the row until a later run succeeds (`ShowErrors = false` on CreateWindow turns that off).

## Value types

What `Get()` returns, what the Callback receives, and what a config saves. `Set` takes the same type as `Get`.

| Kind | Value | Callback receives |
|---|---|---|
| Toggle | boolean | on |
| Button | none | nothing (on press) |
| Buttons | none | `Changed` fires with the pressed button's Title |
| Slider | number, or `{ low, high }` with Range | value |
| Dropdown, Radio, Chips, Segmented, List, Tiles, ItemGrid | the picked Value (a list with Multi) | value |
| Checklist, Tags | list | list |
| Input | string, or number with Numeric | value |
| Keybind | Enum.KeyCode or nil; `{ Key, Ctrl, Shift, Alt }` with Modifiers | Press: nothing; Toggle and Hold: on |
| ColorPicker | Color3 | color, transparency |
| DatePicker | `{ Year, Month, Day, Hour, Minute }` | that table |
| Stepper, Rating, Knob, Gauge, Progress | number | value (Gauge and Progress have no Callback) |
| Countdown | seconds left | nothing (at zero) |
| Status | its words | none |
| PlayerList | picked player's Name (Selectable) | Actions get the Player |
| Waypoints | `{ { Name, CFrame } }` | the list |
| Chart | items or series | the data passed to Set |
| Viewport | the source model | the model |
| Graph | list of numbers | the newest value (Push) |
| Log | every line as text | none |

## I want to...

| I want to | Use |
|---|---|
| switch a feature on and off | Toggle (add `Keybind` and `Color` add-ons on the same row) |
| run something once | Button (`Confirm` or `Hold` when it can't be undone; `Keybind` for a key) |
| let only one of several modes be on | Toggle with the same `Exclusive` group, or Segmented/Radio |
| ask before a risky feature turns on | Toggle `Confirm = "why it's risky"` |
| pick a number | Slider; Stepper for small exact counts; Knob for a compact dial |
| pick from a list | Segmented (2-4), Radio (2-6), Dropdown (many or dynamic), List (visible, reorderable), Tiles (with icons), ItemGrid (inventory with pictures, counts, rarity) |
| type text and check it | Input with `Validate` |
| show a live figure | Stat/Stats; Gauge for a share of a maximum; Graph or Chart for history and comparisons |
| preview a model or the character | Viewport |
| save and return to places | Waypoints |
| tell the player something happened | `Notify` (Id to update one notice in place; Countdown = "Edge" for the outline timer) |
| keep a running status on screen | `Notify({ Id = "status", Duration = 0 })` updated with the same Id, or a PopOut section with Stats |
| put deep settings out of the way | `Tab:Page` / `Section:Page`, or `Window:Sheet` for a slide-over panel |
| let players keep their own shortlist | `Favourites = true` |
| let players move settings between devices | share codes: the config block's copy/paste rows, or `ExportConfig`/`ImportConfig` |
| keep separate settings per game in one universal hub | `Configs = { PerGame = "Universe" }` |
| make the window feel alive | `Background = { Kind = "Aurora" }` on the window, at most one or two sections with their own |
| tell players about a new version | `UpdateCheck = { Url = ... }` |
| help players report bugs | Settings tab rows Executor support and Errors, or `SupportPanel()` / `ErrorsPanel()` |
| build a control Halcyon lacks | `Halcyon:RegisterElement` |
| describe the hub as data | `Halcyon:Build(spec)` |
| show the hub in another language | `Language = "auto"` or a code; `Strings` for your own wording of built-in text |

## Components

Each entry: what it is for, when not to use it, options with defaults, value and callback, looks, phone behaviour, mistakes.

### Toggle
- For: an on/off feature (Fly, ESP, Auto farm).
- Not for: actions that happen once (use Button); choosing between named modes (use Segmented/Radio).
- Options: `Default` [false], `Style`, `Thumb` ("Circle" | "Oval" | "Square"), `Outline` [window], `OutlineColor`, `Keybind = { Default = Enum.KeyCode.X, Mode = "Toggle" | "Hold", Flag, Modifiers }`, `Color = { Default, Alpha, Flag, Callback }`, `Exclusive = "group"` (at most one toggle of that group is on; turning one on turns the others off), `Confirm` (true or a sentence: a press asks before turning on; turning off never asks).
- Value: boolean. Callback(on) on every Set and once at start if `Default = true`.
- Looks: Switch (default), Large, Slim, Square, Labelled, Icon, Glow, Checkbox, Circle, Chip.
- Add-ons: `handle.Keybind` (key chip beside it), `handle.Color` (swatch beside it), each with its own Flag.
- Phone: the whole row is the press target.
- Mistakes: naming it "Enable X"; a toggle that does a one-shot action; forgetting to undo the feature when it turns off.

### Button
- For: an action now (Teleport, Rejoin, Collect all).
- Not for: a setting that stays on (Toggle).
- Options: `Variant`/`Style` ("Row" default: the whole row is the button; "Filled", "Outline", "Danger", "Soft", "Ghost", "Gradient", "Success"), `Icon` (inside a drawn button), `TrailingIcon` (row look), `Effect` ("Sweep", "Ripple", "Lift", "Glow", "Press", "Fill", "None"), `Hold` (seconds to hold), `Confirm` (true or wording of the confirming second press), `ShowDone` (tick or cross after the Callback), `Keybind` (Enum.KeyCode or `{ Default, Flag, Modifiers }`: a key chip on the row that presses the button).
- Value: none. Callback() on press; `Press()` runs it. `SetLoading(bool, text)` blocks presses with a spinner; `IsLoading()`. A Callback that yields shows the spinner by itself until it returns.
- Mistakes: Danger look without Confirm/Hold for destructive actions; many Filled buttons on one page (one primary per section reads best).

### Buttons
- For: two to four related actions side by side (Save / Load, Accept / Decline).
- Options: `Buttons = { { Title, Icon, Variant, Callback } }`, optional `Title` above.
- Value: none. `Changed` fires with the pressed title.
- Mistakes: more than four buttons; unrelated actions in one row.

### Slider
- For: a number in a known range (speed, FOV, distance).
- Not for: a handful of named levels (Segmented), unbounded numbers (Input with Numeric), exact counts (Stepper).
- Options: `Min` [0], `Max` [100], `Step` [1], `Default` [Min], `Suffix`, `Prefix`, `Percent` (show share of range), `Format = function(v) return text end`, `Display` ("Box" typed value [default], "Text", "Fraction", "None"), `DefaultMarker`, `Range` (two knobs, value { low, high }), `Stacked` (track under the title), `Width` [130], `Tooltip` [window], `TooltipStyle` ("Rounded", "Sharp", "Pill", "Plain"), `Live` [true; false calls back once on release].
- Value: number (or { low, high }). Callback on change while dragging (or on release with Live = false), and on Set.
- Looks: Line (default), Thin, Thick, Handle, Ticks, Bare, Block.
- Phone: the track moves under the title in narrow rows.
- Mistakes: expecting Default to be applied; Live = true for something expensive (use Live = false); Step finer than the game uses.

### Dropdown
- For: one or several choices from a list too long for Segmented (maps, players, weapons).
- Not for: 2-4 options (Segmented or Radio show them all at once).
- Options: `Values` (plain values, or `{ Text, Value, Icon, Image, Description, Disabled }`, or `{ Heading = "Group" }`), `Default` [first value unless AllowNone/Placeholder], `Multi`, `AllowNone`, `Placeholder`, `Searchable` [auto above 8 values], `Width` [150], `Players = true` (server players, kept up to date), `ExcludeSelf`.
- Value: the chosen value or nil; with Multi, a list in Values order. `Refresh(values)` replaces the options and drops vanished picks.
- Looks: Box (default), Minimal, Chips (picks as removable chips), Inline (list opens in the row).
- Mistakes: rebuilding the element to change options (use Refresh); using Text as identity when Value differs.

### Radio
- For: one of 2-6 options that should all be visible.
- Options: `Values`, `Default` [first], `Inline` (side by side), `AllowNone`.
- Value: one value.

### Checklist
- For: several independent on/off items of one kind (loot to collect, mobs to target).
- Options: `Values`, `Default` (list), `Inline`, `SelectAll` (true or its label).
- Value: list in Values order.

### Chips
- For: compact tag-like choices (game modes, filters).
- Options: `Values`, `Default`, `Multi`.
- Value: one value, or a list with Multi.

### Tiles
- For: picking among a few visual options (teleport spots, loadouts) where an icon helps.
- Options: `Items = { { Title, Icon, Image, Description, Value, Disabled } }`, `Columns` [3; 2 on narrow rows], `Multi`, `Default`, `AllowNone`, `Height`.
- Value: one value or a list.
- Mistakes: more than ~9 tiles (use Dropdown).

### Segmented
- For: 2-4 short, mutually exclusive modes (Low / Medium / High).
- Options: `Values`, `Default`, `Stacked`.
- Value: one of Values.

### Input
- For: free text or an unbounded number (a player name, a message, an amount).
- Options: `Default`, `Placeholder`, `Numeric` (with `Min`, `Max`), `MaxLength`, `Counter`, `Live` [false: callback when typing ends], `Width` [150], `LeadingIcon`, `Clearable`, `Password` (dots while not typing), `MultiLine` (with `Lines` [4]), `Validate = function(value) return false, "reason" end` (refuses a value; the reason shows under the field).
- Value: string, or number with Numeric. Invalid numeric text or a refused value is rejected and the old value kept. `SetError(text)` shows the hub's own message under the field; `SetError(nil)` clears it.
- Looks: Boxed (default), Underline, Filled, Pill.
- Mistakes: Live = true for something that runs on every keystroke and is expensive.

### Keybind
- For: a key the player chooses for an action.
- Options: `Default` (Enum.KeyCode; with Modifiers also "Ctrl+F" or `{ Key, Ctrl, Shift, Alt }`), `Mode` ("Press" default, "Toggle", "Hold"), `ModePicker` (right-click or long press to change mode), `Modifiers` (Ctrl, Shift and Alt combinations), `ChangedCallback(key)`, `ModeChangedCallback(mode)`.
- Value: Enum.KeyCode or nil; with `Modifiers = true`, `{ Key, Ctrl, Shift, Alt }` or nil. Callback() on press (Press), Callback(bool) for Toggle and Hold. `GetMode()`, `SetMode(name)`.
- Looks: Chip (default), Keycap, Brackets.
- Notes: press the chip then a key; Escape cancels, Backspace clears. Keys typed into text boxes are ignored. A Toggle's own `Keybind` option is usually better than a separate Keybind row.

### ColorPicker
- For: a colour (ESP colour, highlight).
- Options: `Default` (Color3), `Alpha` (adds transparency), `Transparency`, `Palette` (true or list of Color3), `Recent` [true].
- Value: Color3 (and transparency). Callback when a drag ends or a hex is typed, not every move. `Set` accepts a hex string.

### DatePicker
- For: a date and optionally a time (schedule, event).
- Options: `Default = { Year, Month, Day, Hour, Minute }` [today], `Time`, `WeekStart` ("Monday" | "Sunday"), `Width`.
- Value: that table. `GetTimestamp()`.

### Stepper
- For: a small exact count (amount to buy, number of runs).
- Options: `Min`, `Max`, `Step` [1], `Default` [0], `Suffix`, `Drag` [true: drag the number sideways].
- Value: number.

### Rating
- For: a small level choice shown as icons (1-5 strength).
- Options: `Max` [5], `Default` [0], `Icon` ["star"], `AllowNone`.
- Value: number.

### Progress
- For: showing progress the hub measures (quest, download).
- Options: `Value` [0], `Max` [100], `Suffix`.
- Value: number; `Set(n)` moves it. No Callback.
- Mistakes: faking progress on a timer.

### Status
- For: a state the player should see at a glance (Online, Patched, Farming).
- Options: `Status` (words), `Kind` ("success", "warning", "danger", "info", "muted"), `Pulse`.
- `SetStatus(text, kind)`, `SetPulse(bool)`. Words always state the state; colour is never the only signal.

### Countdown
- For: time left until something the hub knows (boss spawn, cooldown).
- Options: `Seconds` or `Ends` (os.time value), `Done` (text at zero), `Format`, `Callback` (at zero).
- `Set(seconds)`, `SetEnd(timestamp)`, `Get()` seconds left.

### Table
- For: rows and columns of read-only data (leaderboard, item stats, logs).
- Options: `Columns` ("Name" or `{ Title, Width = 0..1, Align }`), `Rows`, `Sortable` [true], `MaxHeight` [220], `Striped` [true], `EmptyText`, optional `Title`.
- `SetRows(rows)`, `AddRow(values)`, `Clear()`. Numbers sort as numbers.

### Accordion
- For: help text, FAQ, patch notes inside a tab.
- Options: `Content` (rich text), `Open`.
- `SetOpen(bool)`, `Set(content)`.

### Paragraph
- For: a titled block of explanation.
- Options: `Content` (rich text), `Icon`, `Image`, `ImageSize` [48], `Buttons = { { Title, Variant, Callback } }`.
- `Set(text)` or `Set({ Title, Content })`.

### Label
- For: one line of text; callouts for info, warnings, success.
- `Label("text")` or `Label({ Title, Style = "Plain" | "Info" | "Success" | "Warning" | "Danger" | "Note", Icon })`. `SetKind(name)`.
- Mistakes: using Warning callouts for routine text (they lose meaning).

### Divider, Space, Code, Image
- `Divider({ Title })`: a rule, optionally titled.
- `Space({ Height = 8 })`: empty room.
- `Code({ Title, Code })`: a code block with a copy button; `Set(code)`.
- `Image({ Image, Height = 140, Crop })`: any image source.

### MenuButton
- For: a short list of actions on one thing (a config: Rename, Duplicate, Delete).
- Not for: a choice that stays picked (Dropdown).
- Options: `Text` ["Actions"], `Icon`, `Items = { { Title, Icon, Callback, Danger, Disabled }, { Divider = true } }`, `Width`.
- Value: none. Each item's Callback runs and the menu closes.

### Link
- For: an address the player should open elsewhere (Discord invite, website, key page).
- Options: `Url`, `Icon` (before the title). The line under the title shows the site.
- Value: the address. A press copies it (Roblox cannot open a browser); without a clipboard the address shows in a box to select.

### List
- For: picks shown in place (a route, ores to mine) or an order the player drags (target priority).
- Not for: long lists in a tight section (Dropdown).
- Options: `Values` (plain values or `{ Text, Value, Icon, Description }`), `Default`, `Multi`, `Search`, `Reorder`, `Height` [200, then it scrolls].
- Value: the picked value; with Multi a list in Values order; with Reorder every value in its current order.

### Tags
- For: free-typed words kept as chips (a whitelist of names, words to watch for).
- Options: `Default` (list), `Placeholder`, `Suggestions` (offered while typing), `Max`, `AllowDuplicates` [false, case-insensitive].
- Value: a list of strings. Enter adds; the × on a chip removes. At Max the entry box hides.

### PlayerList
- For: acting on players in the server (Spectate, Teleport to, Whitelist).
- Options: `Actions = { { Title, Icon, Callback(player) } }`, `Search` [true], `ShowSelf` [false], `Selectable` [false], `Height` [240].
- Value: with Selectable, the picked player's Name. Rows follow joins and leaves.
- Mistakes: assuming the local player is listed (ShowSelf); doing server-owned things from an action.

### Stat and Stats
- For: figures the player reads at a glance (FPS, ping, coins per hour, session time).
- `Stat({ Title, Value, Unit, Change, Kind, Icon, Style = "Card" | "Plain" })`: `Set(value)`, `SetUnit(text)`, `SetChange(text, kind)`. A Change starting with + is green and - red unless Kind is "good", "bad" or "neutral".
- `Stats({ Items = { { Title, Value, Unit, Change, Kind, Icon, Key } }, Columns = 3 })`: a grid, as many to a line as fit; `Set(key, value)`, `Get(key)`, `Items[key]`.
- Mistakes: updating every frame (once a second is plenty).

### Graph
- For: a short history of a number (frame rate, ping, coins per minute).
- Options: `Values`, `Max` [40 kept], `Min`, `Ceiling` (fixed range; otherwise it fits the values), `Height` [80], `Suffix` or `Format` (newest value beside the title), `Role` ["accent"], `Style` = "Line" | "Area" | "Bars".
- Value: the list of values. `Push(value)` adds one; `Set(list)`; `Clear()`.

### Log
- For: lines the hub writes as it works (what it bought, what failed).
- Options: `Height` [180], `MaxLines` [200], `Timestamps` [true], `EmptyText`.
- Methods: `Add(text, level)` with level "info" | "success" | "warn" | "error", `Info`, `Success`, `Warn`, `Error`, `Clear()`. Value: every line as text. Has level filters, copy and clear buttons.
- Mistakes: logging every frame or every toggle.

### Viewport
- For: a 3D preview of a model (a pet, a weapon, the player's character).
- Options: `Model` (any Model or BasePart; copied, never moved), `Character = true` (the local character, refreshed on respawn), `Height` [180], `Spin` (degrees a second, only while its tab shows), `Distance` (fitted when left out), `FieldOfView` [40].
- Value: the source model. `Set(model)` swaps it; `ResetView()` turns it back. Drag to turn it.

### Gauge and Knob
- Gauge: a ring the hub fills (health, cooldown, progress to a goal). Options: `Value`, `Min` [0], `Max` [100], `Suffix`, `Format`, `Size` [72], `Thickness`, `Role` ["accent"], `Thresholds = { { At = 0.25, Role = "danger" } }` (the role at or below that share). `Set(n)` eases the ring.
- Knob: a ring the player turns. Options: `Min`, `Max`, `Step` [1], `Default`, `Suffix`, `Format`, `Size` [64], `Live` [true]. Drag up or right, scroll, or arrow keys. Value: number.
- Not for: a precise number the player types (Slider's value box or Stepper).

### Chart
- For: comparing numbers. `Type = "Donut" | "Pie"` with `Items = { { Name, Value, Role } }` (shares of a whole; hovering a slice shows it in the middle). `Type = "Line" | "Bars"` with `Labels` and `Series = { { Name, Values, Role } }` (hovering shows every series at that label).
- Options: `Height`, `Min`, `Max`, `Suffix`, `Format`. Roles default to accent, info, success, warning, danger in turn; the legend names each colour.
- Methods: `Set(itemsOrSeries)`, `SetLabels(list)`, `Push(values, label, keep)` (one value per series, trims to `keep`).
- Not for: one number's recent history (Graph is lighter).

### ItemGrid
- For: picking from an inventory (pets, eggs, weapons) where the picture, count and rarity matter.
- Options: `Items = { { Title, Image, Icon, Rarity, Count, Value, Disabled } }`, `Rarities = { { Name, Role or Color } }` lowest first [Common, Uncommon, Rare, Epic, Legendary, Mythic], `Multi`, `Default`, `AllowNone`, `Search` [on above 8 items], `Sort` ("Rarity" | "Name" | "Count"), `Columns` [fitted], `Height` [260].
- Value: the picked Value (a list with Multi). `Refresh(items)` keeps picks that still exist; `SetCount(value, count)` updates one card.

### Waypoints
- For: places the player saves and teleports back to.
- Options: `Flag` (keeps the list in configs and share codes), `Teleport = function(cframe, name) end` (without it the local character is moved with PivotTo), `GetPosition = function() return cframe end` [the character's root part], `Default`, `Max` [50], `Height` [220].
- Value: `{ { Name, CFrame } }`. `Teleport(nameOrIndex)`. Names edit in place; rows reorder and delete.

### Banner
- For: an announcement or a game's art at the top of a tab.
- Options: `Title`, `Text`, `Image` (any image source; without one it sits on an accent tint), `Height` [132], `Button = { Title, Callback }`. Narrow, the button drops under the words.
- Methods: `SetText`, `SetImage`.

## Recipes

**A feature that turns on and off cleanly**
```lua
local RunService = game:GetService("RunService")
local noclipConnection
Movement:Toggle({ Title = "Noclip", Flag = "Noclip", Callback = function(on)
	if noclipConnection then
		noclipConnection:Disconnect()
		noclipConnection = nil
	end
	if on then
		noclipConnection = RunService.Stepped:Connect(function()
			local character = game.Players.LocalPlayer.Character
			if not character then return end
			for _, part in character:GetDescendants() do
				if part:IsA("BasePart") then part.CanCollide = false end
			end
		end)
	end
end })
Window.OnUnload:Connect(function()
	if noclipConnection then noclipConnection:Disconnect() end
end)
```

**A loop tied to a toggle.** Each switch-on starts a new run and every older run notices it is stale, so toggling fast never leaves two loops going.
```lua
local farmRun = 0
Farm:Toggle({ Title = "Auto farm", Flag = "AutoFarm", Callback = function(on)
	farmRun += 1
	local thisRun = farmRun
	if not on then return end
	while farmRun == thisRun do
		-- one step of farming
		task.wait(0.5)
	end
end })
Window.OnUnload:Connect(function() farmRun += 1 end)
```
(The Callback runs on its own thread, so the loop can sit inside it.)

**A toggle with its key and colour on one row**
```lua
local esp = Visuals:Toggle({
	Title = "Player ESP", Flag = "ESP",
	Keybind = { Default = Enum.KeyCode.E, Flag = "ESPKey" },
	Color = { Default = Color3.fromRGB(255, 80, 80), Flag = "ESPColor", Callback = function(color) end },
	Callback = function(on) end,
})
```

**A list that changes while the hub runs**
```lua
local target = Combat:Dropdown({ Title = "Target", Players = true, ExcludeSelf = true, AllowNone = true, Placeholder = "Nearest" })
local map = World:Dropdown({ Title = "Map", Values = {} })
map:Refresh(listOfMapNames) -- never rebuild the element
```

**A status the hub keeps updating**
```lua
local coins = 0
local function report()
	Window:Notify({ Id = "farm-status", Title = "Farming", Content = `{coins} coins so far`, Duration = 0, Countdown = "None", Close = false })
end
-- call report() after each step; the same Id updates the notice instead of stacking a new one
```

**UI that mirrors the game without firing callbacks**
```lua
humanoid:GetPropertyChangedSignal("WalkSpeed"):Connect(function()
	speedSlider:SetSilent(humanoid.WalkSpeed)
end)
```

**Settings, configs and sharing**
```lua
local Window = Halcyon:CreateWindow({ Title = "Fishing", Folder = "Fishing", Configs = { PerGame = "Universe" } })
-- ... tabs ...
Window:SettingsTab() -- theme, language, scale, keys, configs with share-code rows, support, errors, unload
Window:LoadAutoload()
```

**Deep settings on a page, a live panel that pops out**
```lua
local aim = Combat:Section({ Title = "Aim" })
aim:Toggle({ Title = "Aim assist", Flag = "Aim" })
local prediction = aim:Page({ Title = "Prediction", Description = "How far ahead to aim at moving targets" })
prediction:Section({ Title = "Lead" }):Slider({ Title = "Lead time", Flag = "Lead", Min = 0, Max = 1, Step = 0.05 })

local live = Farm:Section({ Title = "Session", Side = "Right", PopOut = true })
local stats = live:Stats({ Items = { { Title = "Coins", Key = "coins", Value = 0 }, { Title = "Per hour", Key = "rate", Value = 0 } } })
```

## Wrong and right

| Wrong | Right | Why |
|---|---|---|
| `Section:Toggle("Fly", function() end)` | `Section:Toggle({ Title = "Fly", Callback = function(on) end })` | every constructor takes one table |
| `Section:Toggle({ Name = "Fly", OnChanged = fn })` | `Title`, `Callback` | invented options are ignored; Debug names them |
| `Window:Notify(...)` inside every Toggle callback | no notice; the switch shows the state | notices are for results the player can't see |
| `while on do ... end` with a global `on` | the run-counter loop in "Recipes" | fast toggling starts two loops |
| `slider:Set(x)` inside the slider's own Changed handler | `slider:SetSilent(x)` | Set runs the Callback and fires Changed again |
| destroying and remaking a Dropdown to change its list | `dropdown:Refresh(values)` | keeps the pick, the flag and the row's place |
| `Default = 50` on a speed Slider and nothing else | also apply 50 to the game, or `Set(50)` after building | Default is only displayed |
| `task.spawn(function() pcall(callback) end)` around your own callbacks | plain callbacks | Halcyon runs and guards them already |
| `TextLabel.Text = "Guardar"` on a Halcyon instance | `Language = "es"` or `Strings = { ["Save"] = "Guardar" }` | instances are rebuilt; edits are lost |
| `BackgroundColor3 = Color3.fromRGB(...)` on Halcyon parts | a Theme (`AddTheme`) or `SetAccent` | literal colours ignore theme changes |
| a Background on every section | one on the window, one or two highlighted sections | moving surfaces compete with the content |

## Messages Halcyon prints

Errors (the call stops):
- `Toggle needs a Title` (any kind), `Toggle expects a table of options`
- `Flag "X" is already used by "Y"`, `A Flag must be a non-empty string`
- `Tab needs a Title`, `Page needs a Title`, `CreateWindow expects a table of options`
- `ShowWhen needs an element, or the Flag of one`
- `This section has no tab called "Name"`
- `Halcyon:Build Tabs[2].Sections[1].Elements[3]: unknown kind "Togle", did you mean "Toggle"?`
- `"Toggle" is already an element kind` (RegisterElement)

Warnings (the hub carries on):
- `[Halcyon] Fly callback failed: <reason>`: the row shows the reason too; fix the callback
- `[Halcyon] ShowWhen names the Flag "X", but no element has it.`
- `[Halcyon] Tier "Name" is not one of this window's tiers, so what it gates stays locked.`
- `[Halcyon] Window:Set doesn't know the switch "Name".`
- `[Halcyon] Config value for "Flag" was skipped: <reason>`
- `[Halcyon] Icon pack "name" could not be loaded; icons outside the built-in set stay blank.`
- `[Halcyon debug] Toggle "Fly": unknown option "Defualt", did you mean "Default"?` (Debug only)
- `[Halcyon debug] Toggle look "Glo" doesn't exist; did you mean "Glow"?` (Debug only)

## Translation

- `Language = "auto"` follows the player's Roblox language; codes: "en", "pt-br", "es", "vi", "id", "ru", "tr", "fr", "de". Regional codes fall back ("es-mx" -> "es", any Portuguese -> "pt-br"), unknown ones to English. Default "en".
- `Strings = { ["Unload the hub?"] = "Close everything?" }` replaces Halcyon's own wording, keyed by its English text; placeholders like `{name}` stay in the replacement. `Halcyon:GetStrings()` lists every key used so far.
- The Settings tab has a Language row; the player's pick is saved and wins over the hub's Language on the next run.
- `Translate = true` also translates the hub's own text: tab and section names, row titles and descriptions, dropdown and segment options, placeholders, tooltips, menus, dialogs and notices. Nothing else to write; the window's Title (the hub's name) stays as written.
  ```lua
  Halcyon:CreateWindow({ Title = "Farm", Folder = "Farm", Language = "auto", Translate = true })
  -- or, with options:
  Translate = {
  	From = "en", -- the language the hub is written in [en]
  	Fixes = { de = { ["Auto farm"] = "Auto-Farmen" } }, -- your wording wins over the service
  	Skip = { "Halcyon", "Blox Fruits" }, -- text left as written (names)
  	Service = function(lines, from, to) return translatedLines end, -- your own translator
  }
  ```
- How it works: every string the hub passes in options (and later to SetTitle, SetDescription, SetContent, Refresh and notice setters) is noted as hub text; labels showing it show the translation instead. Values, flags, callbacks and configs keep the text as written, so `Dropdown:Get()` still returns "Forest". Search matches both.
- Translations come from `Fixes`, then a file saved per language (`Halcyon/<Folder>/translations/en-de.json`), then the service. The default service is Google's free translate endpoint; it gets the hub's wording only, about 40 lines a request, with numbers swapped for markers ("123 coins" and "124 coins" are one line). Text typed by the player is never sent.
- Left as written: the window's Title (the hub's name) and `Skip` entries, even inside a longer line; gaming terms players read in English (Ping, Keyless, Aimbot, Noclip, Hitbox, Anti-AFK) and all-capital acronyms (FPS, ESP); one-word codes, versions, file names and links ("Halcyon1:...", "v2.3.1"). A few common hub words have set translations (Dashboard, Memory, News, Features, Free, Paid). Halcyon's own Settings tab and config block are never sent; their words come from the language packs.
- Until a line comes back, and if the service fails (it is given up on after 3 tries), the text stays as written. In Roblox Studio a LocalScript can't make web requests, so pass `Service` to try it there.
- Switching language in Settings re-translates the hub's text at once; Halcyon's built-in words follow on the next run.
- Write hub text as plain sentences: one label per string, no rich text tags (they are left as written), numbers inside the sentence rather than glued from pieces.

## Building from a table

```lua
local Window, elements = Halcyon:Build({
	Window = { Title = "Farm", Folder = "Farm", Debug = true },
	Tabs = {
		{ Title = "Farm", Icon = "sprout", Sections = {
			{ Title = "Auto", Elements = {
				{ "Toggle", Title = "Auto farm", Flag = "AutoFarm", Callback = function(on) end },
				{ "Slider", Title = "Range", Flag = "Range", Min = 10, Max = 200, Default = 80 },
			}, Pages = {
				{ Title = "Timing", Elements = { { "Stepper", Title = "Delay", Id = "delay", Min = 0, Max = 10 } } },
			} },
		} },
		{ Title = "World", Elements = { { "Button", Title = "Rejoin", Id = "rejoin", Callback = function() end } } },
	},
	SettingsTab = true, -- or its options table
	Autoload = true, -- default; loads the autoload config after building
})
-- elements.AutoFarm, elements.delay: handles by Flag or Id
```
Each element is `{ "Kind", ...options }`. Tabs, sections and pages take `Sections`, `Elements` and `Pages`. A mistake names its place in the spec. Returns nil when a key prompt was closed.

## Custom elements

```lua
Halcyon:RegisterElement("Counter", {
	Options = { Step = "number", Default = "number" }, -- for Debug and editor types
	Value = "number",
	Build = function(row, options, handle)
		local value = options.Default or 0
		local plus = Halcyon.Internal.Create.new("TextButton", { Text = "+", Size = UDim2.fromOffset(row.reach, row.reach), Theme = { BackgroundColor3 = row.controlRole, TextColor3 = "text" }, Parent = row.slot })
		function handle:Get() return value end
		function handle:Set(newValue)
			value = tonumber(newValue) or 0
			row.fire(value) -- fires Changed and runs the Callback (skipped during SetSilent)
		end
		row.scope:connect(plus.Activated, function() handle:Set(value + (options.Step or 1)) end)
	end,
})
Section:Counter({ Title = "Clicks", Flag = "Clicks", Step = 2 })
```
- The kind is one capitalised word and can't replace a built-in one. It works on tabs, sections, groups, pages and sheets, with Flag, configs, Tier locks, search, ShowWhen, Reset and Debug.
- `row` gives: `slot` (the control area on the right), `belowTitle()` (a full-width area under the title), `placeControl(control, width, height)`, `onNarrow(fn)`, `onHover(fn, target)`, `fire(...)`, `run(callback, after, ...)`, `scope` (`connect`, `add`), `controlRole`, `reach` (40 on touch, 28 otherwise), `window`, `library`, `handle`.
- Colour with `Theme = { Property = "role" }` in `Halcyon.Internal.Create.new`; icons with `Halcyon.Internal.Create.icon(name, size, role, parent)`.
- Don't create a ScreenGui, run per-frame work while idle, or call the Callback while building. For values that aren't plain JSON (colours, positions), add `handle:Encode()` and `handle:Decode(saved)`.

## Key system

```lua
KeySystem = {
	Title = "My Hub access", Note = "Where to get a key", Icon = "key-round",
	SaveKey = true, MaxAttempts = 5, Cooldown = 30, DefaultTier = "Free",
	ShowExpiry = true, ButtonEffect = "Sweep",
	Discord = "https://discord.gg/yourcode", -- invite button and label under the prompt; opens Discord or copies the link; false/nil leaves it out
	OnSuccess = function(access) end, OnFail = function(message) end,
	Tiers = { -- lowest to highest
		{ NoKey = true }, -- "Keyless": continue with no key, listed first
		{ Name = "Free", Description = "…", Keys = { "KEY" }, Link = "https://…", LinkLabel = "Get a key", Duration = 86400 },
		{ Name = "Free", AdService = { Name = "Linkvertise", Link = "https://…", Confirm = function(key) return ok, message end } },
		{ Name = "Paid", Validate = function(key) return ok, message end },
		{ Name = "Paid", Remote = { Url = "https://…", Method = "POST", Headers = {}, Body = function(key) return body end, Accept = function(body, status) return ok, message end } },
		{ Name = "Staff", Keys = { "…" }, Paid = true },
	},
}
```

- "Free" is a key the player earns (usually via an ad service); never give Free `NoKey`. No key = "Keyless".
- One tier only: put `Keys`, `Remote`, `Link` at the top level and omit `Tiers`. A top-level `Validate(key)` may return true or a tier name.
- `access` = `{ Tier, Rank, Tiers, PaidRank, Key, Saved, Data, ExpiresAt, ShowExpiry }`. Tiers may set `Icon` and `Tag` for their card.
- Locks: `PaidOnly = true` (any paid tier) or `Tier = "Name"` (that tier or higher) on an element, section or tab. "Paid" is paid by default; `Paid = true` marks another tier; tiers above a paid one are paid.
- No key system and no Tiers: the tier is "Keyless"; locked rows stay locked.
- `Confirm`/`Validate`/`Remote` must ask the hub's own server or the ad service's API. Halcyon cannot detect a finished ad and bundles no endpoints; never invent any.
- Running `CreateWindow` again in the same session reuses granted access; `KeySystem.Reprompt = true` asks again.

## Profile

`Profile = false` hides the card. Otherwise a table, all optional:
- `Avatar` ("Headshot" | "Viewport" | "None"), `Anonymous`, `ShowUsername`, `ShowTier`, `ShowExecutor`, `ShowClock`, `ShowDate`, `ClockFormat`, `DateFormat`, `Name`, `Subtitle`
- `Discord = "https://discord.gg/yourcode"`: a round invite button beside the tier, separate from the key prompt's. A table `{ Link, Icon }` sets your own mark; the default is the Discord logo.

## Notifications

```lua
local notice = Window:Notify({
	Title = "Config saved", Content = "…",
	Kind = "info" | "success" | "warning" | "danger",
	Style = "Default" | "Timer" | "Compact" | "Banner" | "Progress" | "Accent" | "Glass" | "Achievement" | "Snackbar" | "Island",
	Icon = "save", Duration = 4, Progress = true, Sound = false, Close = true, Indeterminate = false,
	Actions = { { Title = "Undo", Callback = fn } },
	Countdown = "Bar" | "Edge" | "Ring" | "Top" | "None", -- how the time left shows; Edge drains the card's border
	Id = "farm-status", -- a later notice with the same Id updates this one instead of stacking
	Merge = true, -- identical notices fold into one with a count; false keeps them apart
	Image = "rbxassetid://…", Avatar = player.UserId, -- a picture instead of the icon
	OnClick = function(notice) end, OnDismiss = function(reason) end, -- reason: timeout, closed, clicked, swiped, action, cleared, code
})
-- notice.Dismiss(), SetTitle(t), SetContent(t), SetKind(kind), SetProgress(0..1), Restart(seconds), Done(title, kind) (also Complete)
-- Window:ClearNotifications() / Halcyon:ClearNotifications() dismiss everything
```

- Hovering pauses the countdown; a sideways drag dismisses; the × shows on hover (always on touch); `Close = false` removes it. Past `MaxVisible`, a pill counts the waiting ones.
- `NotificationCenter = true` keeps the last 50 behind a bell in the top bar.

- `Duration = 0` stays until tapped. A Progress notice stays until `Done`.
- Positions: TopLeft, TopCenter, TopRight, BottomLeft, BottomCenter, BottomRight (narrow screens use the top). Island always sits at the top centre.
- Snackbar shows its first action as a word (Undo).

## Dialogs and panels

- `Window:Dialog({ Title, Content, Icon, Dismissible, Buttons = { { Title, Variant = "Primary" | "Danger" | "Ghost", Delay = seconds, Callback } } })`. Name buttons by outcome ("Delete", "Keep"). `Delay` holds a button back with a countdown. Dismissible: a press outside or Escape closes.
- `Window:Loading({ Title, Text, Icon })` -> `{ SetProgress(fraction, text), Done() }`: report real setup steps only.
- `Window:Changelog({ Version, Title, Entries = { { Kind, Text } }, Force })`: a What's new card shown once per version.
- `Window:About(tab, { Description, Credits = { { Name, Role } }, Discord, Links = { { Title, Url } } })`: links copy on press.
- `Window:Lock({ Title, Text, Icon, Button = { Title, Callback } })`, `Window:Unlock()`: maintenance or update screens.

## Images

Anywhere an image or icon is accepted:
- an icon name ("sword", "solar:home"), an asset id (1234, "rbxassetid://1234", "rbxthumb://...")
- an http(s) URL: downloaded once to Halcyon/assets/, shown through getcustomasset
- a workspace file ("myhub/logo.png"): must stay inside the workspace

Images over 5 MB are refused. Without getcustomasset (Studio, some executors) an image icon shows instead. `Halcyon:Image(source, callback)` gives you an id for your own use.

## Extending the library

For a hub's own control, use `Halcyon:RegisterElement` (see "Custom elements"); no source changes needed. To change Halcyon itself: source is in src/; dist/Halcyon.luau, dist/Halcyon.rbxmx and dist/Halcyon.types.luau are generated by `node tools/bundle.mjs`. Every option an element reads must be listed in src/Core/Schema.luau, every `Strings.get` text needs an entry in each src/Locales pack, and LLM.txt must mention every schema option: `node tools/test.mjs` checks all three. To add a built-in element: create src/Elements/Name.luau exporting `Name.new(container, options)`, build on `Row.new(container, options, layout)`, put controls in `row.slot`, give `row.handle` Get and Set, call `row.fire(value)` from Set, connect through `row.scope`, colour with `Theme = { Property = "role" }`, and add it to MODULES in src/Elements/Registry.luau. Add tests under tests/ and run `node tools/test.mjs`. An element must not create its own ScreenGui, run per-frame work, use literal colours for themed parts, or call its Callback while being created.
